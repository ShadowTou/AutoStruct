## 🧠 Overview  
**AutoStruct** is a lightweight CLI tool designed for developers who want to:  
- Instantly check detailed **system information** (OS, processor, disk usage, etc).  
- Quickly **generate a clean project folder structure** with predefined directories like `src`, `tests`, `docs`, and more.  

Perfect for automation lovers, sysadmins, or Python developers who set up multiple projects frequently.  

---

## ⚙️ Features  
✅ Display detailed system info (cross-platform)  
✅ Show disk usage (`wmic` for Windows / `df -h` for Unix-like systems)  
✅ Auto-create project folders with a predefined structure  
✅ Auto-generate a `README.md` template  
✅ Safe and customizable
